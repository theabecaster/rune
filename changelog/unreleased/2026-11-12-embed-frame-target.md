- **Embedding: `LayerHost::frame_at(target)` steps a frame to the time it will be on screen.** A host with a display link passes the link's target time, so motion is drawn where it will be when the frame shows and a late frame loses no time, as in a window; `frame()` is `frame_at(now)`. The host also tells the frame clock when each frame was presented, so motion a slow frame started moves one frame on the next instead of jumping by the overrun, and a compositor that is still animating keeps running motion on real time. An iOS `RuneView` passes its `CADisplayLink`'s `targetTimestamp`.
