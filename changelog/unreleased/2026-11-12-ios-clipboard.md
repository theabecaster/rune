- **iOS: copy and paste use the system pasteboard.** `Tx::copy`, `Tx::copy_rich`, a field's copy and cut, and pastes go through `UIPasteboard`: text, HTML, RTF and an image as PNG in one item; files aren't written. A secret copy stays on the device, off the Universal Clipboard, and is cleared when its time is up. An embedded view's host turns the system clipboard on with `LayerHost::with_system_clipboard` and sends keys through `LayerHost::key`, which reads the clipboard for the paste shortcut; a `RuneView` does both. iOS asks the user to allow a paste of what another app copied.
