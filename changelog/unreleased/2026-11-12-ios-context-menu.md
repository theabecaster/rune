- **iOS: a long press opens menus, shown as the system's edit menu.** A finger held on something with a menu (a text field, selectable text, an element with `on_secondary_press`) is a secondary press, and a menu a handler asks for with `Tx::popup_menu` shows as the bar iOS puts above a selection, with separators as groups, checked and disabled items and submenus. A text field's Cut, Copy, Paste and Select All work by touch, and a long press on selected text keeps the selection. `popup_menu_supported()` is true on iOS. An embedded view's host that shows menus itself says so with `LayerHost::with_popup_menus`; others still answer every menu `None`.
