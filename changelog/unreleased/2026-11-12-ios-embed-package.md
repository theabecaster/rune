- **iOS: `scripts/ios-lib` builds an app's library as an XCFramework, and the `RuneView` Swift package shows it in SwiftUI.** `scripts/ios-lib --package P --module M --header H` builds `P`'s library as a static library for devices and Apple silicon simulators (`cargo rustc --crate-type staticlib`, so the package's manifest asks for none) and writes `target/ios/M.xcframework` with the C header and a module map that links the frameworks rustc names, so a host app imports `M` and adds no linker flags. `ios/RuneView` is a Swift package with one `UIViewRepresentable`: `RuneView(my_exported_view)` takes a function that returns `rune::ios::view(app)`. `examples/web-hello` exports `web_hello_view` on iOS, with its header in `examples/web-hello/include`.
