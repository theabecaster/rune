- **iOS: `Tx::open_file` shows the system's document picker.** The picker opens over the screen the `RuneView` is on, filtered to the dialog's extensions, and answers with a copy of the chosen file inside the app's container, or `None` when cancelled. Save and folder dialogs answer with an error. An embedded view's host that shows file dialogs itself says so with `LayerHost::with_file_dialogs`; others still refuse every dialog.
