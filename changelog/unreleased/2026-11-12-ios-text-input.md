- **iOS: the keyboard types into text fields.** While a text field has the focus, a `RuneView` shows the soft keyboard and answers UIKit's text input protocol from the field's text: typing, delete, return, predictions, autocorrection and marked text (Japanese, Chinese, dictation) edit it, and a hardware keyboard types through the same path. A secure field shows the keyboard none of its text. The keyboard's height counts as the bottom of `Cx::safe_area` while it shows, so a root padded by the safe area lifts above it.
