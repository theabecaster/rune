- **iOS: an App's menu items work.** `App::menu_item` and `AppHandle::set_menu` no longer answer Unsupported on iOS. On an iPad the items join UIKit's main menu (the menu bar and the list a held ⌘ shows): app-menu items follow About, an item in a menu named File, Edit, Format, View, Window or Help goes at the end of that system menu, any other name gets a menu of its own before Window, and separators become sections. An item with a shortcut is a key command there. On an iPhone, which has no main menu, an item's shortcut runs it when no handler takes the key, as a `keys_first` item's does everywhere. Dock items and anchors on AppKit actions have no place on iOS.
